Identity used when adding memories from the extension

On by default. This decides whether HipCortex watches the AI chat pages you are already reading — it does not send anything anywhere new, and nothing is captured from a site you have not allowed below. Turn it off here or from the toolbar popup to stop automatic captures; the toolbar button still captures one conversation when you ask it to.

Which sites HipCortex may read

HipCortex can only read a conversation on a site you have allowed it to read. Nothing is captured from a site that is not allowed, and the toolbar icon shows a ! until every one of them is.

Move records between cores

Import a memory export from another HipCortex core into this one. Every record is written the way a capture is, so the destination decides what it keeps — a field this build does not define refuses the whole file rather than half importing it.

The core regenerates each record's id, so an import breaks any reference that named the old one. Old-to-new is recorded as the import runs, which is what the lookup below reads.

Answers with the id the destination issued for it, or that it is not in the remap — which is a different answer from an empty remap, and both are shown.
